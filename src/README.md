# Timeseries Forecast

Grafana app that fits univariate models from `timeseries-forecast` and overlays the forecast window on the query history.

Add the **Forecast overlay** visualization to a panel, pick a data source, and choose a model. Mixed metric + Forecast datasource queries are supported on the overlay (Forecast frames are not fitted or plotted there). After a snapshot is saved, the nested **Forecast** datasource can emit forecast / interval series for Grafana alerting by `refId`. Overlay options **New alert rule** builds a complete rule from the panel state: the metric rows plus one synthesized Forecast row that restores the trained snapshot, both over `now - lookback … now`, with two Reduce(`last`) nodes, a Math percent deviation and a Threshold on it as the condition; **Alert series** (shown only when the panel has more than one series) is the only input. Grafana’s panel Alert tab is on Time series, not this overlay. The backend caps train size and concurrent Fit / ForecastRange work (413/429); the overlay limits in-flight loads per panel. The Docker Grafana environment is the sibling `timeseries-grafana-sandbox` (provisioned: minute-of-week overlay and Metrics vs baselines).
